## YouTube Optimization

### Ranking Factors

| Factor | Weight | Optimization |
|--------|--------|--------------|
| Watch Time | 30% | Engaging content, retention hooks |
| CTR | 25% | Thumbnail + title optimization |
| Engagement | 20% | Comments, likes, shares |
| Relevance | 15% | Keywords, tags, descriptions |
| Channel Authority | 10% | Subscriber count, consistency |

### Title Optimization

```
Formula:
[Primary Keyword] + [Value Prop] + [Hook/Modifier]

Examples:
✗ "How to Cook Pasta" (generic)
✓ "Perfect Al Dente Pasta in 10 Minutes | Chef's Secret"

✗ "SEO Tips" (too broad)
✓ "7 SEO Hacks That Actually Work in 2025 [With Proof]"
```

### Description Template

```
First 200 Characters (CRITICAL - shows in search):
[Main topic] + [What you'll learn] + [Value proposition]

Full Description:
📌 In this video, you'll learn:
• Point 1
• Point 2
• Point 3

⏱️ Timestamps:
0:00 - Intro
1:30 - [Topic 1]
5:45 - [Topic 2]
10:00 - [Topic 3]
15:00 - Summary

🔗 Resources Mentioned:
• [Link 1]
• [Link 2]

📱 Connect:
• Twitter: [link]
• Website: [link]

#hashtag1 #hashtag2 #hashtag3
```

### Thumbnail Best Practices

| Element | Guideline | Why |
|---------|-----------|-----|
| Resolution | 1280x720 minimum | Clarity on all devices |
| Text | 3-4 words max | Readable on mobile |
| Faces | Include when possible | 1.5x higher CTR |
| Contrast | High contrast colors | Stand out in feed |
| Branding | Consistent style | Recognition |

### LinkedIn SMO

**Algorithm Factors**:
```
Ranking Signals:
1. Dwell Time (how long people read)
2. Early Engagement (first hour critical)
3. Share-to-Comment Ratio
4. Connection Relevance
5. Content Format
```

**Content Formats by Performance**:

| Format | Avg Reach | Best For |
|--------|-----------|----------|
| Document/Carousel | Highest | Tutorials, guides |
| Native Video | High | Behind-scenes, tips |
| Text + Image | Medium | Quick insights |
| Text Only | Medium | Opinions, stories |
| External Link | Lowest | Save for comments |

**Posting Template**:
```

↳ Problem or insight

↳ Story or data

↳ Key takeaways (bulleted)

↳ CTA (question to drive comments)

---
Hashtags at end (3-5)
```

## Amazon MEO

### A9/A10 Algorithm

```
Ranking Factors:
├── Relevance (40%)
│   ├── Title keywords
│   ├── Backend search terms
│   ├── Bullet points
│   └── Description
│
├── Performance (35%)
│   ├── Sales velocity
│   ├── Conversion rate
│   ├── Click-through rate
│   └── Sales history
│
├── Customer Satisfaction (15%)
│   ├── Reviews (qty + quality)
│   ├── Return rate
│   ├── Customer questions
│   └── Seller rating
│
└── Inventory & Pricing (10%)
    ├── Stock levels
    ├── Price competitiveness
    └── Fulfillment method
```

### Title Formula

```
[Brand] [Product Line] [Key Feature] [Product Type] [Size/Qty] [Color/Variant]

Example:
"TechBrand ProMax Wireless Noise-Cancelling Headphones with 40H Battery - Black"

Character limits:
• Standard: 200 characters
• Mobile display: ~80 characters (front-load keywords)
```

### Bullet Points

```
Template:
[BENEFIT IN CAPS] - Feature explanation with keyword integration

Examples:
• CRYSTAL CLEAR AUDIO - Advanced 40mm drivers deliver studio-quality
  sound with deep bass and crisp highs for immersive listening
• ALL-DAY COMFORT - Memory foam ear cushions and adjustable headband
  provide comfortable fit for extended wear
```

### Backend Keywords

```
Rules:
• 250 bytes max
• No punctuation needed
• No repetition from title
• Include misspellings
• No competitor brand names
• Separate with spaces

Example:
wireless earphones bluetooth earbuds noise canceling
noice cancelling headset audio music sport workout gym
```

## Amazon Rufus Optimization

### How Rufus Works

```
User Query: "What's a good gift for a runner?"
     ↓
Rufus Analysis:
├── Intent: Gift-giving, running-related
├── Category: Sports & Outdoors
├── Price sensitivity: Gift-appropriate
└── Features: Popular, well-reviewed
     ↓
Response: Curated recommendations with reasons
```

### Optimization Tactics

1. **Rich Product Data**
   - Complete all attributes
   - Add lifestyle images
   - Include use cases in bullets

2. **Review Quality**
   - Encourage detailed reviews
   - Respond to questions
   - Address use cases

3. **Content Depth**
   - A+ Content with comparison charts
   - Brand story
   - Feature explanations
