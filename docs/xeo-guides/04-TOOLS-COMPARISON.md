## Tool Selection Framework

### Decision Matrix

```
Question 1: What's your monthly budget?
├── <$100 → Startup Stack
├── $100-500 → Growth Stack
├── $500-2000 → Agency Stack
└── $2000+ → Enterprise Stack

Question 2: What's your primary focus?
├── B2B SaaS → GEO-heavy stack
├── E-commerce → MEO-heavy stack
├── Local Business → LEO-heavy stack
├── Media/Content → VEO/SMO-heavy stack
└── Agency → Full coverage
```

### Trial Strategy

**30-Day Trial Schedule**:
```
Week 1: GEO tools (Otterly, Profound)
Week 2: SEO tools (Semrush, Ahrefs)
Week 3: Content tools (Clearscope, Frase)
Week 4: Evaluate and decide
```
